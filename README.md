# Threat Hunting Exercises Lab

Hypothesis-driven threat hunting practice for SOC Analyst skill development.

## Overview

This repository documents structured threat hunting exercises performed against real lab telemetry (Sysmon, Windows Event Logs, PowerShell logs, Wazuh, Microsoft Sentinel). It includes a repeatable methodology, foundational and intermediate exercises, and professional documentation of findings.

## What’s Included

| File | Description |
|------|-------------|
| `Threat_Hunting_Exercises_Report.docx` | Portfolio lab report (Word) |
| `Threat_Hunting_Exercises_Report.md` | Same report in Markdown |
| `Threat_Hunting_Exercises_Guide.md` | Methodology and exercise guide |

## Skills Demonstrated

- Hypothesis-driven hunting methodology
- Hunting across Sysmon, Security Event Logs, and PowerShell logs
- Process, authentication, PowerShell, network, and DNS hunts
- Correlation of multiple telemetry sources
- Validation hunting with Atomic Red Team
- Linking findings to MITRE ATT&CK
- Turning hunt results into detection opportunities

## Related Labs

Builds directly on **Sysmon**, **Windows Event Log**, **PowerShell Security Monitoring**, **Wazuh**, **Microsoft Sentinel**, **Atomic Red Team**, and **MITRE ATT&CK Detection Mapping**.
